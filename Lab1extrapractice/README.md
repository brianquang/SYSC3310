# Lab 1 extra practice 

Takes a array of my student number: {1, 0, 1, 2, 9, 7, 1, 0, 3}
For each 1s we find in my student number, it blinks an LED to its corresponding position.

In this example it would blink once for the first 1, three times for the next 1, and seven times for the final 1, with a pause between groups, then blinks ten times to indicate completion:
