# SYSC3310 – Introduction to Real-Time Systems

This repository contains my lab work and assignments completed throughout the **SYSC3310 – Introduction to Real-Time Systems** course at Carleton University.

## Course Overview

This course covers the fundamentals of real-time systems, including embedded programming, hardware interfacing, interrupts, timers, and real-time system design.

## Repository Contents

This repository is organized by lab and contains the source code, project files, and supporting materials for each lab.

| Folder | Description |
|---|---|
| Lab 1 | Getting Started with C coding |
| Lab 2 | C coding (Manipulating bits) |
| Lab 3 | Basic I/O |
| Lab 4 | I/O with interrupts |
| Lab 5 | Timer |

*Folder descriptions can be updated as more labs are added.*

## Tools & Technologies

- **Programming Languages:** C
- **IDE:** Keil MDK
- **Microcontroller:** Texas Instruments MSP432P401R
- **Hardware:** MSP432 LaunchPad
- **Debugging:** Keil Debugger

## Purpose

This repository serves as a collection of my coursework and practical experience with embedded systems and real-time programming.
